# Mi Portafolio Profesional 🚀

Bienvenido/a al repositorio de mi portafolio digital. Se ha usado Git para el control de versiones y se publica de forma automática mediante GitHub Pages.

## 🛠️ Tecnologías Utilizadas
- **HTML5** para la estructura de la página.
- **CSS3** para la maquetación, diseño responsive y estilos visuales.
- **JavaScript (Vanilla)** para las funcionalidades interactivas y animaciones.

## 📖 Secciones de la Web
1. **Inicio:** Presentación y frase personal.
2. **Sobre mí:** Biografía, intereses y objetivos.
3. **Formación académica:** Línea temporal de estudios.
4. **Habilidades:** Competencias técnicas y personales.
5. **Experiencia:** Prácticas y trabajos realizados.
6. **Proyectos:** Cuadrícula interactiva de tarjetas.
7. **Contacto:** Formulario visual y enlaces profesionales.

## ✨ Retos de Diseño Implementados
Como requisito de la actividad, he introducido las siguientes 3 mejoras sobre la propuesta inicial de la IA:
1. **Selector de Modo Claro / Oscuro:** Cambio dinámico de colores guardado en el `localStorage`.
2. **Efecto Typewriter:** Animación de máquina de escribir en JavaScript para el texto de presentación.
3. **Efectos Hover Interactivos:** Sombras dinámicas verde lima/coral en las tarjetas de proyectos.
